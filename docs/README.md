## Agregar un documento

1. Abre un issue con la plantilla **Cambio en Documentación** (`[Docs]: ...`).
2. Crea la rama según la guía, por ejemplo `docs/15-niveles-agregar-diseno`.
3. Guarda el archivo en esta carpeta, con un nombre descriptivo. Si es texto, prefiere Markdown (`.md`): GitHub lo muestra directamente y los cambios se pueden revisar en el diff del PR.
4. Agrégalo a la tabla de arriba con una línea que diga qué contiene.
